Board view shows every open workspace on a host as a kanban board, with one column per workspace status, ordered so a workspace moves left to right as it progresses: Working, Needs input, Failed, Ready to review, and Done. Labels match the sidebar status grouping.

Open it from the "Board view" row in the sidebar header or from the Command Center. Cards move between columns live as agents start, finish, or ask for input. Each card shows the workspace title, project, branch, time in the current status, diff size, and linked pull request when there is one. Pressing a card opens that workspace.

On narrow windows and mobile the columns stack vertically. Archived, background, and internal workspaces are hidden. The board reads workspaces from the host selected in the screen header and does not send data anywhere else.
