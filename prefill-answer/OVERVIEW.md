Agents often end a turn by asking a question or proposing a next step. Prefill answer gives every agent a `prefill_answer` tool so it can also put the reply it recommends into your message box. When the turn finishes, the proposed reply is waiting in the composer: press Enter to accept it, or edit it first.

The proposal only appears after the turn completes. A turn that fails or is canceled drops it, and starting a new turn clears it. The composer is only filled when it is empty, so text you already typed is never replaced. It also works for agents that are not on screen: the reply is there when you open the agent.

The tool is added to every agent session, so agents start using it without setup. Agents decide when to call it based on the tool description; nothing leaves the daemon machine.
